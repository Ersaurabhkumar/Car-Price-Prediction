Car Price Prediction Model

Developed and deployed a machine learning model for predicting car prices using a REST API. Conducted extensive exploratory data analysis (EDA) to understand the data distribution, identify patterns, and detect outliers. Tried several regression algorithms to find the optimal model, with KNeighborsRegressor yielding the best performance.

Key responsibilities and contributions:

Data Cleaning & Preprocessing: Removed duplicate entries, handled missing values, and performed feature engineering to prepare the dataset for model training.

Model Selection: Experimented with multiple regression models, including Linear Regression, Random Forest, and KNeighborsRegressor.

Data Transformation: Applied normalization and scaling techniques to ensure the model could generalize well on new data.

Deployment: Deployed the model via a REST API using Flask, enabling real-time predictions.
